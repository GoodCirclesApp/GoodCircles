How this database works

Built from the free ProPublica Nonprofit Explorer API (public IRS Form 990 data). Each profile is a research starting point, not an endorsement or application portal — always confirm current priorities and how to apply with the funder. Refreshed periodically. Last verified 2026-06-17.
